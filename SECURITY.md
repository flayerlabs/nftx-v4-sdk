# Security policy

## Supported versions

Until the first stable release, security fixes are made only on the latest
published `0.x` version. After `1.0.0`, the current major version will be
supported.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/flayerlabs/nftx-v4-sdk/security/advisories/new>

If private reporting is unavailable, contact a repository maintainer privately
before sharing technical details. Include the affected SDK version, chain,
contract addresses, reproduction steps, and potential impact. Do not include
private keys, seed phrases, RPC credentials, or other secrets.

We will acknowledge a report, investigate it, and coordinate disclosure once a
fix is available. No response-time or bounty commitment is made by this policy.
